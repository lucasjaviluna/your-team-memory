# Registro de iteraciones

Cada archivo documenta una unidad de cambio verificable. Nombre recomendado:
`NNN-descripcion-corta.md`.

## Plantilla

```markdown
# Iteración NNN — Título

Fecha:
Estado: propuesta | en curso | completa

## Objetivo

## Alcance

## Decisiones

## Cambios realizados

## Verificación

## Memoria MCP

## Deuda o próximos pasos
```

No se considera completa una iteración que cambie un contrato o flujo sin actualizar
su ficha en `documentation/components/` o `documentation/architecture/`.
